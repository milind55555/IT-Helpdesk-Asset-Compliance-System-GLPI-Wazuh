# SOP-05: User onboarding

**Purpose:** Provision approved access and equipment for a new starter.

## Inputs
Approved request, manager/owner, start date, role, department, location, required applications, data access, and equipment.

## Procedure
1. Validate approval and confirm the requester's authority.
2. Create/verify the user identity in the approved identity platform using a unique identifier.
3. Assign role-based groups and minimum required application permissions; avoid direct broad admin rights.
4. Enforce approved authentication and MFA enrolment. Deliver initial credentials through a secure channel.
5. Assign an inventoried endpoint and peripherals; record asset ID, custodian, and handover acknowledgement.
6. Install approved software, apply endpoint protection and patch baseline, and enrol the endpoint in Wazuh if in scope.
7. Provide VPN, email, printer, and knowledge-base access only where approved.
8. Test sign-in and required services with the user.
9. Update GLPI ticket and asset records; capture approvals and completion date.
