# SOP-02: Printer troubleshooting

**Purpose:** Diagnose common printing failures.

## Procedure
1. Record requester, printer asset ID/hostname, location, error, document type, and start time.
2. Check power, display errors, paper, toner/ink, tray selection, and physical connectivity.
3. Confirm the endpoint is on the expected network and can resolve/reach the approved print server or printer address.
4. Check whether the issue affects one user, one device, or all users.
5. Inspect the print queue. Cancel only the affected stuck job after confirming with the user.
6. Verify the approved driver and printer mapping; do not install drivers from untrusted websites.
7. Submit a small test page and ask the requester to validate.
8. Record the fix, parts/consumables used, and any vendor reference.

**Escalate:** Suspected hardware fault, network-wide print outage, unsafe physical condition, or repeated device failure.
